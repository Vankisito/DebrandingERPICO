Erpico POS Debranding
=====================

Extensión de la suite `erpico_debranding` para punto de venta (POS) de
Odoo 19.

Sustituye la línea "Powered by Odoo" del recibo de venta (`order_receipt.xml`)
por "Powered by ERPICO" mediante un QWeb template de mayor prioridad.

Requiere `point_of_sale`.
