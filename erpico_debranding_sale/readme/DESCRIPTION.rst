Erpico Sale Debranding
======================

Extensión de la suite `erpico_debranding` para el portal de ventas y
compras de Odoo 19.

Elimina el botón "Connect with your software!" (`portal.portal_content_boot`
/ `sale.portal_content_boot`) y su modal de ficheros EDI de las páginas
públicas de cotizaciones y órdenes de compra, reemplazando la referencia a
Odoo por el contexto ERPICO.

Requiere `erpico_debranding`, `sale` y `purchase`.
